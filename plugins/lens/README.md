# lens plugin

Visual exploration tools — diagrams, charts, and architecture visualization.

## Skills

| Skill | Description |
|---|---|
| `/diagram` | Generate a Mermaid diagram from a description or current context and return a mermaid.live link |

## Usage

```
/diagram
/diagram flowchart of the timeout call logic
/diagram sequence diagram showing the outbound call flow
```

If called with no arguments, the skill infers the subject from the current conversation context.
